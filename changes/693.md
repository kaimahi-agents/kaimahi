### Changed

- Copilot Chat Completions and Responses file Run/Test and MCP previews now use embedded Agent Sessions and the private cleartext journal, with one Session per judge sample and the shared two-sample scoring policy. Provider-owned preflight keeps source and exchanged credentials out of journal content, logs and results; preview credentials never refresh mid-run or trigger inference retries. Expiry or authentication refusal stops later sends; logout in another process does not interrupt an existing preview, which stays bounded to five minutes. All file judge routes now stop later sends on malformed or unavailable replies. Verbose preview diagnostics use fixed safe classes instead of direct-runner per-request HTTP status/timings. Judge payloads and reasoning are retained under the existing 20-run retention and clearing policy. Replay makes zero model calls and is not evaluation evidence. Copilot tool execution remains unsupported.
