### Added

- Local preview library for one tool-free single-file agent. It runs in process
  on embedded Sessions with a private, bounded SQLite journal, against kmx's
  deterministic fake model or an explicit OpenAI-compatible endpoint, and
  reuses the existing assertions and `llmJudge`. The journal keeps
  instructions, inputs and answers in cleartext, never credentials; an answer
  echoing the endpoint credential is refused. Each new run prunes to the
  newest 20 runs, never deleting one still executing, and journals can be
  cleared per run or all at once. On Windows the journal is under `%AppData%` (roaming profile).
  Journal inspection replays a run with no model call and gives no verdict.
  Results are labeled local preview, not deployment qualification. There is no
  CLI command yet; see [local preview](https://github.com/kaimahi-agents/kaimahi/blob/main/docs/local-preview.md).
