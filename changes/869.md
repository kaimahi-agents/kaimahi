### Added

- Resident Markdown agents use shared discovery for Ollama/Foundry Local and
  support OpenAI-compatible and Anthropic Messages endpoints. Credentials are
  environment references and require HTTPS; loopback HTTP remains keyless.
- Match context/output-token and reasoning requirements with exact model profiles,
  `modelRequirements` frontmatter, and offline `kmx model match`. Unknown required
  capabilities refuse activation. Relative profile paths are supported.

### Fixed

- Verify exact-model catalog access before replacement readiness, preserving the
  old worker and sessions on failure. Exact reuse retains its worker's credential
  snapshot without requiring the caller to export that key again.
- Bound retained start records before caching/publication, reuse endpoint
  connection pools, and keep default output budgets within declared limits.
- Support authenticated HTTPS Ollama metadata through gateway prefixes.
- Separate resident flags from preview help, preserve live Run failure exits,
  and print `--prompt` in Create's next-command guidance.
- Make test fixtures independent of shell/checkout permissions and macOS path
  aliases. Linux/macOS resident lifecycle tests are part of required hygiene.
